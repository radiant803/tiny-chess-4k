A chess engine in 4,096 bytes of Python 3.13: a 0x88 board, alpha-beta with a
transposition table, killers, history ordering and quiescence search, packed
into `main.py` with the competition kit's compressor.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3.13 -P -s main.py
```
